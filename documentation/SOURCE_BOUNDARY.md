# Source Boundary

## Included

- Original Stata `.do` files from the paper-specific RoadCapacityInducedDemand source folder.
- Small original Excel workbook outputs from the same folder.
- Modern `.xlsx` conversions of those workbooks.
- The published paper reference PDF.

## Not Included

- Public source data such as NPTS and FHWA Highway Statistics bulk files.
- Stata `.dta` files that appear to be intermediate or derivative working datasets.
- Stata logs and run outputs.
- Drafts, correspondence, presentations, resumes, and broad project folders.

## Reproducibility Note

The original scripts use old Mac-style paths such as `:Macintosh HD:Desktop Folder:paper:...`. Those paths are preserved in the original code rather than silently rewritten. Those legacy paths are documented as provenance and are not an archive blocker; the staged package is intended to preserve the original analysis assets rather than silently rewrite them.
